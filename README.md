# ZYONE

Site responsivo de perfumaria e cuidados pessoais, com catálogo de produtos e pedidos pelo WhatsApp.

- **WhatsApp:** +55 (68) 99992-7870
- **Atendimento:** Thailanna Moura · Ponto de Apoio ZYONE
- **Tecnologias:** HTML, CSS e JavaScript, sem dependências de instalação.
- **Prévia original:** https://zyone-thailanna-moura.grupopasdiora.chatgpt.site

## Arquivos

- `index.html`: conteúdo, catálogo, preços e links de contato.
- `styles.css`: identidade visual e layout responsivo.
- `script.js`: menu de navegação no celular.
- Imagens PNG: fotografias usadas no site.
- `.nojekyll`: indica que a publicação utiliza arquivos estáticos.

## Abrir e editar

Abra `index.html` no navegador para visualizar localmente. Para atualizar os preços, textos ou telefone, edite `index.html`. Os links de WhatsApp usam o formato internacional `5568999927870`.

## Pedidos

Os botões abrem o WhatsApp com o produto e o valor preenchidos. A disponibilidade, o pagamento, o frete e o prazo de entrega são combinados no atendimento. O site não processa pagamentos nem envia mensagens automaticamente.

## Publicação no GitHub Pages

Use a branch `main` e a pasta `/(root)` em **Settings → Pages → Deploy from a branch**. Os caminhos de imagens e estilos são relativos, compatíveis com o endereço do projeto.

As imagens e a marca foram fornecidas para este projeto.
